# Backlog — идеи вне текущей волны

Правило из CLAUDE.md: фичи вне текущей волны не делаются, а записываются сюда с волной-кандидатом.

| Идея | Зачем | Волна-кандидат |
|---|---|---|
| Событие для вебхука без подписи (сейчас: нет подписи → `Webhook.signature: nil`, в INTEGRATION.md только примечание) | Явный warning для жюри: «уведомления не аутентифицируются» | 3 (вместе с S3) — потребует нового кода в реестре (изменение контракта §3.3) |
| `Response.example_source` (`media | named | composed`) в IR | Фикстуры могли бы помечать составленные из property-examples примеры отдельно от объявленных | по запросу; изменение контракта |
| Полный маппинг enum провайдерских кодов ошибок (не только по HTTP-ответам) в INTEGRATION.md | Таблица «Provider error codes» для операционной команды | 3 |
| Экспонента валюты для конверсии по `currency` из `example`, а не только из константы enum | Мультивалютные провайдеры | 4 |
| Подсветка уверенности в `/analysis` веб-слоя | Демонстрация «как без нейросети» | 5 |
| Поля `customer.*` (payer, ip, email) в теле запроса — сейчас не отправляются (у канона нет аккессора) | pay-in провайдеры требуют данные плательщика | 3 (расширение `canonical_contract.yml → operation.accessors`) |
| `FieldSchema`: ветки `oneOf` как `oneOf` в JSON Schema (сейчас все поля веток optional) | точнее валидация fixtures для S2 | 2–3 |
| Статус во вложенном объекте ответа (`result.state`) — `status_path` берёт только верхний уровень | провайдеры с конвертом `{ result: {...} }` | 3 |
| Подпись в `fixtures.json` (`signature` с тестовым секретом) для мок-сервера и генерируемого RSpec | e2e без ручного HMAC | 2 (RspecGenerator считает сам) |
| `--run-spec`: запуск сгенерированного RSpec сразу после записи, строка `RSpec N examples 0 failures` в транскрипте (PLAN §7) | доказательство прямо в выводе CLI | 2 (вместе с RspecGenerator) |
| `--diff` / W601: сравнение с существующим `output/<slug>/` до перезаписи | сейчас `Pipeline` молча перезаписывает свои же файлы | 4 (по плану) |
| Пофайловый прогресс генерации (`Generator.call` отдаёт файлы по мере готовности) вместо четырёх строк-анонсов перед генерацией | честный по времени вывод на больших спеках и прогресс в веб-слое | 5 |

# Backlog — идеи вне текущей волны

Правило из CLAUDE.md: фичи вне текущей волны не делаются, а записываются сюда с волной-кандидатом.

| Идея | Зачем | Волна-кандидат |
|---|---|---|
| Событие для вебхука без подписи (сейчас: нет подписи → `Webhook.signature: nil`, в INTEGRATION.md только примечание) | Явный warning для жюри: «уведомления не аутентифицируются» | 3 (вместе с S3) — потребует нового кода в реестре (изменение контракта §3.3) |
| `Response.example_source` (`media | named | composed`) в IR | Фикстуры могли бы помечать составленные из property-examples примеры отдельно от объявленных | по запросу; изменение контракта |
| Полный маппинг enum провайдерских кодов ошибок (не только по HTTP-ответам) в INTEGRATION.md | Таблица «Provider error codes» для операционной команды | 3 |
| Экспонента валюты для конверсии по `currency` из `example`, а не только из константы enum | Мультивалютные провайдеры | 4 |
| `rake lf` — нормализация LF после `rubocop -A` на Windows | Удобство разработки | 1–2 |
| Подсветка уверенности в `/analysis` веб-слоя | Демонстрация «как без нейросети» | 5 |
